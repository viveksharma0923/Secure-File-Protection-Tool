🔐 Project Description

This project implements a secure file protection system using cryptographic techniques to safeguard sensitive data. It addresses the limitations of traditional file systems by ensuring that data remains protected even if unauthorised access is gained.

The system encrypts files into unreadable formats and allows access only through proper authentication, preventing misuse, tampering, or data leakage.

Key focus areas:

Confidentiality – Data is encrypted to prevent unauthorised access
Integrity – Ensures files are not modified without detection
Availability – Authorised users can securely access data when needed

This project demonstrates the practical implementation of Information Security concepts and highlights how encryption can be used to secure data at the file level in real-world scenarios.
